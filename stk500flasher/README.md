# STK500 Flasher — плагин прошивки плат для Candle

Плагин добавляет в Candle панель для прошивки плат управления (Arduino / AVR,
GRBL и совместимые) по протоколу **Arduino STK500 v1** (Optiboot) — так же,
как это делает Arduino IDE. Движок прошивки — **avrdude**; протокол зафиксирован:
`-c stk500v1` (выбор программатора в интерфейсе убран как избыточный).

Протестировано с Candle 11.x (актуальная master-ветка). Требуется Candle
с поддержкой JS-плагинов (папка `candleplugins`).

---

## Что нового в версии 2.3

1. **Кнопки «Прошить» и «Стоп» объединены в одну** — двусторонняя кнопка:
   в простое она запускает прошивку, а во время работы avrdude превращается
   в «Стоп» — повторное нажатие прерывает прошивку. Кнопка никогда не
   блокируется, меняется только её надпись и подсказка; панель стала
   ещё проще (одна кнопка вместо двух).

## Что нового в версии 2.2

1. **Убран выбор программатора из панели** — протокол прошивки зафиксирован:
   STK500 v1 (`avrdude -c stk500v1`) через USB-UART самой платы. Список
   вариантов (`arduino`/`wiring`/`usbasp`/`usbtinyisp`/`avrisp`…) был
   избыточен: всё это — внешние аппаратные программаторы или протокол
   STK500 v2 (Mega 2560), они не участвуют при прошивке через порт платы.
   Панель стала проще и ещё немного уже.
2. Если плата не входит в загрузчик по STK500 v1 (редкие клоны), это
   лечится подбором скорости «Бод», а не выбором программатора.

## Что нового в версии 2.1 (компактная панель)

1. **Панель значительно уменьшена**: минимум ~156×212 px вместо ~250×390 —
   теперь она гарантированно помещается в панельную область Candle
   без вертикального и горизонтального скроллбара и без обрезки:
   - 5 строк вместо 6: скорость и программатор объединены в одну строку;
   - короткие подписи (Порт / Бод / МК / HEX / Опции);
   - жёсткие минимальные ширины у всех полей — панель сжимается до ~150 px;
   - **журнал свёрнут по умолчанию** и раскрывается кнопкой «Лог»
     (состояние запоминается). При старте прошивки и ошибках журнал
     открывается автоматически, высота лога ограничена 72 px (внутри —
     собственная прокрутка), поэтому панель не «распухает».

2. Исправлена русская локализация: убрана ссылка на удалённую подпись
   программатора (в русской локали панель больше не ломалась).

## Что было в версии 2.0

1. **Плагин полностью переписан под реальные ограничения скриптового движка
   Candle** — устранены все найденные причины неработоспособности:
   - нажатие «Прошить» больше не вызывает ошибку `ambiguous connect`
     (сигналы `QProcess::finished` и `currentIndexChanged` подключаются
     с явной сигнатурой);
   - вывод avrdude теперь действительно попадает в журнал: `String(QByteArray)`
     в движке Candle возвращает не содержимое, а имя класса — используется
     официальный паттерн `QTextCodec.codecForMib(106).toUnicode(...)`;
   - чтение **обоих** потоков процесса (avrdude пишет весь прогресс в stderr);
   - русская локализация больше не ломает панель (только присваивание
     свойств, никаких `setText()` на кнопках — этих методов нет в биндингах).

2. **Порт UART по умолчанию берётся из настроек Candle** (и обновляется при
   изменении настроек). Скорость по умолчанию — 115200 (стандарт Optiboot /
   STK500 v1), т.к. скорость соединения Candle с GRBL не имеет отношения
   к скорости загрузчика.

3. **Выбор avrdude в настройках плагина** (как в первой версии):
   путь к программе avrdude и (опционально) к avrdude.conf — работает
   и на Linux, и на Windows. Для Windows есть полная сборка архива (full)
   со встроенным avrdude 8.0.

## Установка

1. Найдите папку с программой Candle (рядом с `candle.exe` / `candle`).
2. Скопируйте папку `stk500flasher` целиком в `candleplugins`
   (создайте её при необходимости):

```
Candle/
├── candle(.exe)
└── candleplugins/
    └── stk500flasher/
        ├── config.ini
        ├── script.js
        ├── widget.ui
        ├── settings.ui
        ├── README.md
        └── avrdude/            (только для Windows)
            ├── avrdude.exe
            ├── avrdude.conf
            └── LICENSE
```

3. Перезапустите Candle — в правой панельной области появится блок
   «STK500 Flasher».

## Использование

1. **Отключите соединение с платой в Candle** (Соединение → Отключиться) —
   иначе порт будет занят.
2. В панели «STK500 Flasher»:
   - **Порт** — подставляется из настроек Candle; при необходимости
     обновите список кнопкой «R» и выберите другой;
   - **Бод** — 115200 для Uno/Nano (Optiboot), 57600/19200 для старых
     плат. Прошивка всегда идёт по STK500 v1 — как «Загрузка» в
     Arduino IDE; программатор фиксирован и не выбирается;
   - **МК** — ATmega328P для Uno/Nano/GRBL, ATmega1284P для Sanguino
     (ATmega2560 для Mega — только если на плате Optiboot);
   - **HEX** — файл прошивки (Intel HEX), например `grbl.hex`;
   - **Опции** — дополнительные параметры avrdude (`-D` не стирать чип,
     `-V` не проверять, `-F` игнорировать сигнатуру — осторожно).
3. Нажмите **«Прошить»**. Прогресс записи/проверки виден в индикаторе,
   подробный вывод avrdude — в журнале (кнопка «Лог», при прошивке
   открывается автоматически). В конце — «Готово!» либо описание ошибки.
   Пока прошивка идёт, кнопка превращается в **«Стоп»** — нажмите её ещё
   раз, чтобы прервать процесс.
4. Если плата не входит в загрузчик автоматически — нажмите **RESET** на
   плате сразу после нажатия «Прошить».

## Настройка avrdude (Настройки → STK500 Flasher)

- **Программа avrdude** — путь к avrdude. Пусто = автопоиск:
  1) папка плагина (`avrdude/avrdude.exe`, Windows);
  2) папка программы Candle;
  3) Arduino IDE (Program Files / LOCALAPPDATA);
  4) PlatformIO (`~/.platformio/packages/tool-avrdude/bin`);
  5) системный PATH.
- **avrdude.conf (необязательно)** — свой конфиг; пусто = берётся рядом
  с avrdude (`avrdude.conf`, `../etc/avrdude.conf`, `etc/avrdude.conf`).

**Linux:** `sudo apt install avrdude` (или `pacman -S avrdude`,
`dnf install avrdude`) — будет найден в `/usr/bin/avrdude`, либо укажите
свой бинарник в настройках. **macOS:** `brew install avrdude`.

## Ограничения

- Прошивка идёт через avrdude — это тот же механизм, что использует
  Arduino IDE (STK500 v1 + авто-сброс через DTR).
- Перед прошивкой закрывайте соединение Candle с портом.
- Плата должна иметь загрузчик (Optiboot и т.п.). «Чистые» чипы без
  загрузчика прошиваются только внешним программатором (`usbasp`…).
- Mega 2560 со штатным загрузчиком работает по протоколу STK500 v2
  (вариант «wiring») и по v1 не отвечает — прошивайте её внешним
  программатором или сначала запишите Optiboot.
